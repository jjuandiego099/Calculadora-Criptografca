# 🔐 Calculadora Criptográfica (Streamlit)

Una aplicación interactiva desarrollada en **Python 12** con **Streamlit** que permite explorar, calcular y visualizar conceptos fundamentales de aritmética modular, criptografía clásica, criptografía moderna, funciones hash, codificaciones y manejo de sales (*salts*).

Autor: **Juan Diego Chaparro García**

---

## 🛠️ Contenido de la Aplicación
**La calculadora está estructurada en módulos didácticos:**

1. Operaciones Matemáticas Modulares: Módulo, inverso aditivo, inverso de XOR, MCD, inverso multiplicativo (método tradicional y Algoritmo Extendido de Euclides - AEE).

2. Criptografía Clásica: Cifrados de Módulo 27, César, Vernam, Atbash, Transposición, Afín y Sustitución.

3. Criptografía Moderna: Protocolo de intercambio de claves Diffie-Hellman, RSA y Exponenciación Rápida.

4. Algoritmos Hash: MD5, SHA-256 y SHA-512 (con demostración del efecto avalancha).

5. Codificación: ASCII, Hexadecimal, Binario y Base64.

6. Uso de Salt: Generación y verificación de contraseñas con sales aleatorias usando funciones hash.
